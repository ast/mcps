#+title: smhi-mcp
#+author: Albin Stigö
#+options: toc:t

An MCP (Model Context Protocol) server that connects Claude Code to
the [[https://www.smhi.se/data/sok-oppna-data-i-utforskaren/][SMHI]] (Swedish Meteorological and Hydrological Institute) open
weather API. It provides hourly forecast data so you know how to dress
and what to expect for the day.

For building, installing, and registering with Claude Code, see the
[[file:../README.org][main README]].

* Prerequisites

None beyond the toolchain in the main README — no API key or account
is required, SMHI's forecast data is freely available.

The HTTP client uses a 10-second timeout and identifies itself with a
=smhi-mcp/<version>= user-agent.

* Available tools

| Tool           | What it does                                              |
|----------------+-----------------------------------------------------------|
| =get_forecast= | Fetch an hourly weather forecast for a lat/lon coordinate |

** Tool parameters

| Parameter | Type    | Required | Description                                    |
|-----------+---------+----------+------------------------------------------------|
| =lat=     | float   | no       | Latitude in decimal degrees (default 57.7089)  |
| =lon=     | float   | no       | Longitude in decimal degrees (default 11.9746) |
| =hours=   | integer | no       | Hours ahead to include (default 24, max 240)   |

Defaults point at Gothenburg. Latitude must be in =-90..=90= and
longitude in =-180..=180=; out-of-range or non-finite values are
rejected.

* Security note

=smhi-mcp= only performs outbound HTTPS GET requests to the SMHI open
data API. It does not execute arbitrary code, write files, or require
any credentials.
