#+title: notify-mcp
#+author: Albin Stigö
#+options: toc:t

An MCP (Model Context Protocol) server that lets Claude Code send
desktop notifications via D-Bus, targeting notification daemons such
as [[https://github.com/emersion/mako][Mako]] or [[https://dunst-project.org/][dunst]].

For building, installing, and registering with Claude Code, see the
[[file:../README.org][main README]].

* Prerequisites

A running notification daemon implementing the freedesktop.org
notification spec — Mako, dunst, GNOME Shell, KDE Plasma, etc.
=notify-mcp= talks to it over D-Bus via the [[https://crates.io/crates/notify-rust][notify-rust]] crate, so no
external =notify-send= binary is required.

Quick sanity check that a daemon is listening:

#+begin_src sh
  notify-send "Test" "If you see this, notifications work."
#+end_src

* Available tools

| Tool     | What it does                                                           |
|----------+------------------------------------------------------------------------|
| =notify= | Send a desktop notification with a summary, optional body, and urgency |

** Tool parameters

| Parameter | Type   | Required | Description                                       |
|-----------+--------+----------+---------------------------------------------------|
| =summary= | string | yes      | The notification title / summary                  |
| =body=    | string | no       | Longer description shown in the notification body |
| =urgency= | string | no       | =low=, =normal=, or =critical= (default: normal)  |

Unknown urgency values are rejected with an error rather than silently
falling back to =normal=.

* Example prompts

#+begin_example
When you finish the task, send me a desktop notification.
#+end_example

#+begin_example
Send a critical notification saying "Tests failed".
#+end_example

#+begin_example
Notify me with summary "Build done" and body "All checks passed".
#+end_example

* Security note

=notify-mcp= only sends D-Bus notification messages — it does not
execute arbitrary code or write files. Notification content is
visible on-screen and may be logged by your notification daemon, so
treat anything you ask Claude to surface accordingly.
