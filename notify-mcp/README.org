#+title: notify-mcp
#+author: Albin Stigö
#+options: toc:t

An MCP (Model Context Protocol) server that lets Claude Code send
desktop notifications via =notify-send=, targeting notification
daemons such as [[https://github.com/emersion/mako][Mako]] or [[https://dunst-project.org/][dunst]].

* Prerequisites

- [[https://www.rust-lang.org/tools/install][Rust]] (stable toolchain)
- A running notification daemon (e.g. Mako, dunst)
- =notify-send= available on your =PATH= (typically from =libnotify=)

Verify =notify-send= is installed:

#+begin_src sh
  notify-send --version
#+end_src

* Build & Install

** Build

#+begin_src sh
  git clone https://github.com/yourname/notify-mcp cd notify-mcp cargo
  build --release
#+end_src

The binary will be at =target/release/notify-mcp=.

** Install to PATH

#+begin_src sh
  cargo install --path .
#+end_src

This installs =notify-mcp= to =~/.cargo/bin/=, which should already be
on your =PATH=.

* Adding to Claude Code

** Quick add (local scope)

#+begin_src sh
  claude mcp add --transport stdio notify -- notify-mcp
#+end_src

** Project scope (shared with team via =.mcp.json=)

#+begin_src sh
  claude mcp add --transport stdio --scope project notify -- notify-mcp
#+end_src

** User scope (available in all your projects)

#+begin_src sh
  claude mcp add --transport stdio --scope user notify -- notify-mcp
#+end_src

** Verify it was added

#+begin_src sh
  claude mcp list claude mcp get notify
#+end_src

** Remove

#+begin_src sh
  claude mcp remove notify
#+end_src

* Using in a Claude Session

Once added, start Claude Code normally and the notification tools will
be available automatically. Within a session you can check the server
status with:

#+begin_example
/mcp
#+end_example

** Available tools

| Tool     | What it does                                                           |
|----------+------------------------------------------------------------------------|
| =notify= | Send a desktop notification with a summary, optional body, and urgency |

** Tool parameters

| Parameter | Type   | Required | Description                                       |
|-----------+--------+----------+---------------------------------------------------|
| =summary= | string | yes      | The notification title / summary                  |
| =body=    | string | no       | Longer description shown in the notification body |
| =urgency= | string | no       | =low=, =normal=, or =critical= (default: normal)  |

** Example prompts

#+begin_example
When you finish the task, send me a desktop notification.
#+end_example

#+begin_example
Send a critical notification saying "Tests failed".
#+end_example

#+begin_example
Notify me with summary "Build done" and body "All checks passed".
#+end_example

* Security note

=notify-mcp= only spawns =notify-send= subprocesses — it does not
execute arbitrary code. However, be mindful that notification content
is visible on-screen and may be logged by your notification daemon.
