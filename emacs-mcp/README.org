#+title: emacs-mcp
#+author: Albin Stigö
#+options: toc:t

An MCP (Model Context Protocol) server that lets Claude Code interact
with a running Emacs instance via =emacsclient=.

For building, installing, and registering with Claude Code, see the
[[file:../README.org][main README]].

* Emacs setup

The server talks to Emacs through =emacsclient=, so Emacs must be
running its built-in server. Add this to your =init.el=:

#+begin_src emacs-lisp
  (server-start)
#+end_src

Or start it interactively with =M-x server-start=.

Verify the server is up:

#+begin_src sh
  emacsclient --eval "(emacs-version)"
#+end_src

* Targeting a specific Emacs instance

If you run multiple Emacs servers, set =EMACS_SOCKET_NAME= to pick
which one =emacs-mcp= connects to. Pass it through Claude Code when
registering:

#+begin_src sh
  claude mcp add --transport stdio --scope user \
      --env EMACS_SOCKET_NAME=server2 \
      emacs -- emacs-mcp
#+end_src

When the variable is unset =emacsclient= uses its default socket.

* Available tools

| Tool                  | What it does                                        |
|-----------------------+-----------------------------------------------------|
| =eval_expression=     | Evaluate arbitrary Emacs Lisp and return the result |
| =list_buffers=        | List the names of all open buffers                  |
| =get_buffer_content=  | Get the full text of a buffer (current or named)    |
| =open_file=           | Open a file in Emacs via =find-file=                |
| =get_cursor_position= | Return point, line, column, and current file path   |

* Example prompts

#+begin_example
Look at my current Emacs buffer and summarise what the code does.
#+end_example

* Security note

=eval_expression= can execute arbitrary Emacs Lisp. The =open_file=
and =get_buffer_content= tools escape their string arguments so a
malicious buffer name or path cannot inject elisp, but the general
=eval_expression= tool intentionally does not — only use this server
in sessions you control and be mindful when prompting Claude to
evaluate untrusted expressions.
